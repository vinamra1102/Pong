# Hyper Realistic Pong 🎮

A 3D Pong game made using Python and the Ursina Engine.

I wanted to remake the classic Pong game but in a more cinematic and modern style instead of just using flat 2D graphics. This project helped me learn basic 3D game development, lighting, collisions, camera movement, and simple AI logic.

---

# Features 🚀

- 3D Pong Environment
- AI Controlled Opponent
- Smooth Paddle Movement
- Ball Collision Physics
- Dynamic Camera Angle
- Lighting and Textures
- Score System
- Simple Realistic Style

---

# Tech Stack 🛠️

- Python
- Ursina Engine

---

# Installation 📦

Install Ursina:

```bash
pip install ursina
```

Run the game:

```bash
python main.py
```

---

# Controls 🎯

- Move your mouse up and down to control the left paddle
- Right paddle is controlled by AI

---

# Project Goal 💡

The goal of this project was to experiment with making retro arcade games look more modern using simple Python code.

I also wanted to understand:
- game loops
- collision systems
- entity movement
- 3D scene setup
- lighting systems
